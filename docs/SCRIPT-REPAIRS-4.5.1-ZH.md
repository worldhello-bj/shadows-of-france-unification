# 4.5.1 脚本检查修复

修复 2026-10-06 对发布提交 `a9f475a55721b238c4fa32c6d6f2b4dc91b2aee5` 的四项确认问题。资源分布、80% 初始工业、国策结构、美工、内阁及制造商数值沿用 4.5.0。

| 问题 | 修复 |
| --- | --- |
| R1 特殊工程和突袭辅助脚本缺失 | 移植原版三个通用装备蓝图；移除德国工程的专属制造商奖励、意大利国策专属喷火坦克奖励、印度核打击剧情和菲律宾成就回调；删除不能迁移的暹罗、印尼及中国长城专属突袭。 |
| R2 科西嘉国策陆军经验命令错误 | `SFC_aid_for_the_spanish_republic` 正确奖励 20 陆军经验；设计数据和生成策略同时改用 `army_experience`。 |
| R3 18 份兼容国策科研槽条件错误 | 条件改用 `amount_research_slots < 5`，同步设计数据；保留国策 ID、奖励及兼容选择机制。 |
| R4 殖民自治等级缺少闭括号 | 补齐最外层 `autonomy_state`，保留现有自治规则。 |

移植工程蓝图仅使用原版通用分支，独立于德国、日本、英国、美国等国家的制造商和国策。工程清障车保留 Gotterdammerung 限制，火箭截击机保留 By Blood Alone 限制，冰航母保留 Man the Guns 限制；冰航母九种科技组合全部生成生产队列需要的 `Habakkuk` 型号。核突袭的通用伤害、单位、费用和各档结果脚本保持一致。

`common/scripted_effects` 等目录继续使用独立模组替换。修复采用必要函数的实际移植和无法迁移内容的删除，没有用空函数冒充迁移。两份原先继承的原版突袭文件增加本地覆盖，防止删去的条件和事件链继续被引擎加载。

生成器 `tools/build_script_repairs.py` 使用已审核的源文件和哈希复现修复，无需本地游戏安装；遇到其他修改会拒绝覆盖。校验 `tools/validate_script_repairs.py` 检查全模组脚本括号、失效命令、工程与突袭辅助函数、DLC 限制、生产型号、生成结果及核突袭效果一致性。

修复依据为本机 HOI4 1.19 的效果和条件文档，以及[秋起图书馆脚本条件模板](https://github.com/Paradox-Developer-Foundation/QIUQI-LIBRARY/blob/2dd5ff9b94d9f5277fb22d9b7a8207469f06d9aa/资料/基础代码/常用模板/脚本文件模板/脚本类模板/脚本条件_scripted_triggers.txt)中调用必须对应定义的规范。原版文件和辅助函数目录的来源哈希记录在 `references/script-repairs-4.5.1/` 和 `design/script-repairs-4.5.1.json`。

已有 4.5.0 安装可解压窄补丁并运行 `powershell -ExecutionPolicy Bypass -File ./install-repairs.ps1`。安装前保存并关闭游戏。安装器核验旧文件和新文件哈希，生成回滚备份，拒绝覆盖其他修改；两个描述文件仅调整版本，保留工坊发布标识。

源码检查、安装器情景检查和安装哈希核验不能替代引擎验收。重启游戏后仍需检验工程完成、生产队列、核突袭、科西嘉经验奖励和旧档科研国策；目前不声明这些已在游戏内验证。
