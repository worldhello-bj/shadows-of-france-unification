# 红色马赛 4.3.3候选实现

本次增加52项马赛专属国策，保留153项通用国策的原有ID。新局由原籍MRS选择新树；既有通用树与旧地区树的马赛存档，通过启动／每周更新尝试保留已完成国策并切换。新线路不引用地图上不存在的苏联国家，采用苏维埃经济与军队组织的本土化内容。

52项新国策各用一幅逐项审阅的完整原版插画，导出为96×96透明DDS。检查整棵马赛树的205个sprite、纹理路径、实际像素及去除透明边距后的图像内容，均无重复。新增插画也不重复巴黎、科西嘉已有原稿。来源与哈希记录在`design/marseille-focus-art.json`；不使用改名、换色或添加小徽章来区分同一图案。

## 进入与发展

新档选择马赛，从“组织港口工人”开始。共产党初始35%支持率，经前两项组织国策达到50%；政权交接要求稳定度35%以上、50政治点，并使用已有人物让·克里斯托福尔。政权改为共产主义后，专属奖励接管同用途的旧工业、军事和意识形态奖励。

| 内容 | 已实现规则 |
| --- | --- |
| 政治 | 中央组织与工会路线互斥；党内矛盾每月增加3；政治协调需付费并占用时间；90日危机警告与180日恢复期；稳定后可结束紧急状态。 |
| 经济 | 第一计划365日后验收，第二计划需15个实际拥有并完全控制的法国州；重工业与民生方向互斥；同一计划精神替换升级。 |
| 工程 | 4民工、2军工、1船厂，检查真实建筑槽位；瓦尔铝土矿与已有矿业开发共享防重复标记；铁路逐州检查完整路径。 |
| 军队 | 140日整编期、政治委员、军需组织、群众动员与职业骨干互斥；防御战争分支不阻挡统一主线。民兵项目解锁招募模板，部队仍通过原生招募消耗装备和人力。 |
| 科研 | 额外研究槽需12座民工与军工；马赛通用研究国策和新研究决议均检查4槽上限。 |
| 外交 | 地中海社会主义协约、明确接受／拒绝的邀请与互助、盟内技术合作；离开阵营后取消技术合作奖励。采购与护航须实际使用原生贸易和舰队任务。 |
| 战役 | 陆上与海上战争目标各需50政治点、90日准备；共用一个筹备名额，目标有效180日，不替玩家宣战。海上项目另需4艘军舰、20艘运输船、受控港口及海军国策。 |

| 统一 | 全国建国沿用339州所有权与完全控制条件及一次性建国奖励。占领整合沿用连续控制、顺从度、抵抗度、政治点与装备条件；战后重建需和平180日。 |

每项新国策有独立奖励领取记录；建筑、矿产和外交退款额外检查领取／项目状态。通用国策抽为共享定义，树中只引用8个根节点；检查确认所有153项节点仍可由根节点加载。跨分支前置节点均位于后续节点上方。

## 安装与协作

完整候选包为`dist/shadows-of-france-4.3.3.zip`。已安装红色马赛4.3.3时，使用`dist/shadows-of-france-marseille-icons-4.3.3.zip`，关闭游戏后解压运行`install-marseille-icons.ps1`。此修订只增加52幅DDS、1个注册文件，并替换马赛国策的52个icon字段；布局、前置、奖励和导航捷径逐字保留，描述符不变。

原始路线补丁`shadows-of-france-marseille-4.3.3.zip`不含本次图标修订，图标以完整候选包或独立图标补丁为准。整条路线的打包器继续校验源清单；若共享国策等运行文件存在并行修改，先停止打包，避免将旧快照覆盖到当前安装。

安装器校验旧文件与包内哈希，备份被修改文件和两个描述符；保留本地人物、历史、地图、其他企业数值和特质、发布身份。若同名核心文件存在未识别改动或写入途中检测到并发变动，会停止并回滚本次已写入的文件。安装回执保存实际安装字节的哈希。

仓库内新的制造商成长树内容由当前制造商设计与生成器继续管理。本补丁不会把整份制造商源码覆盖到安装目录；已安装的4项或16项特质均能保留。

## 验证范围

- `tools/validate.py`：原版树对照、共享国策语义、图标与中文引用、既有4.3平衡和制造商、新路线图结构与脚本情景。
- `tools/validate_marseille_red.py`：解析实际完成效果，模拟夺权、奖励防重复、危机90日边界、紧急状态180日边界、计划365日边界、矿产防重复、政体变化、提案拒绝退款和联邦治理登记。
- `tools/verify_marseille_installer.py`：两种制造商版本、重复安装、回滚备份、其他内容及发布身份保留、额外修改和非法路径拒绝。
- `tools/marseille_focus_art.py`：52幅原稿、DDS导出一致性及完整205项图像去重；调用主验证器后，重复图标会阻止完整发布打包。
- `tools/verify_marseille_icons.py`：实际图标合并安装器、并行导航与布局保留、重复安装、备份与错误拒绝；`--installed`核对整个安装目录和实际图标绑定。
- `MARSEILLE-RED-PREVIEW.png`：真实脚本坐标与各项独立图标的源码布局图，非游戏截图。
- `MARSEILLE-ICONS-PREVIEW.png`：52幅实际DDS的原尺寸审阅图，非游戏截图。

隔离启动测试进程在产生日志前异常退出，退出码`0xC0000005`。未取得游戏引擎加载、真实旧存档迁移、实际战役平衡或长期AI行为的验证证据。相关报告保留`game_engine_verified=false`。测试代码只放在隔离目录，不进入发布包。

游戏内验收应使用1.19.3、新档MRS，并另测一个旧档；记录界面比例、树选择、人物、计时项目、目标事件、占领登记及海军行动。安装后需要重新启动游戏读取新文件。
