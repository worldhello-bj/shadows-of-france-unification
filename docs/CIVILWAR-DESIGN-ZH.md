# 法兰西的破碎时代 · 通用内战决议 GUI 美术版 3.2.0

基于20国3.0候选包与3.1通用内战GUI，加入生成背景和原创决议徽章。完整候选包包含20国1,408项国策、通用内战界面及本轮美术。当前游戏安装目录未修改，实机显示和旧档初始化待验收。

## 玩家视觉

- **背景**：内置 `image_gen` 生成的1930年代法国内战插画。破损市政厅、民兵、烟雾和暗色地图组成顶部画面；下方为低对比度地图底纹。没有复制TNO或原版美术。
- **版式**：原生内容区510×500像素，比3.1增加60像素；标题与阶段留在顶部，统计、邻接列表及经验整体下移60像素。暗色衬板保护正文，不遮盖顶部插画。
- **文字**：正文沿用原版 `hoi_16mbs` 16像素中文字体；标题使用原版 `hoi4_typewriter22`。经验仍以文字和勾同时表示，不仅依靠颜色。
- **决议图标**：独立生成11张透明徽章，统一采用黄铜、钢铁、纸张和少量暗红色。32×32像素用于原版决议列表；分类徽章使用原版52×40画布，徽章主体保持比例。保留48、64、128像素PNG供美术审阅。
- **交互**：保留原版决议列表、成本、灰置条件和悬停。动态邻接旗帜支持水平滚动；“更新态势”免费刷新界面汇总。

## 保留的机制与数值

3.2相对3.1只调整显示布局及美术引用。132条决议的费用、执行时间、冷却、目标选择、可用条件、装备消耗、奖励和AI均按AST比较保持一致。国策、科技、国家精神、州历史和地图没有在此覆盖层中修改。

通用面板自动用于独立、未投降且首都位于法国的国家，并读取其当前法国邻接势力。阶段为军令待批、扩张授权、交战阶段和统一重建。地方秩序显示国家稳定度；统一进度为完整控制法国地区数÷339。待整合统计完整控制的法国非核心地区，排除不可通行地区。统计每周更新，也可免费手动刷新；汇总不产生额外奖励。

边境战役仍为25政治点数、45天冷却，需原有扩张授权、和平及合法邻接目标。原生分类从筹备阶段显示，授权限制在决议可用条件中再次核验。战争目标获得后，通过原版外交界面宣战；占领后的登记、重建、协约、清剿继续使用原有地区决议。

永久地形经验沿用3.0数值，同类只获得一次，统一后保留：

|---|---|
| 山地 | 进攻+3%、防御+3%、移动+2% |
| 渡河 | 进攻+3% |

| 登陆 | 两栖登陆进攻+3% |
| 林丘 | 森林与丘陵进攻各+2%、防御各+3% |

除登陆外，适用于步兵、摩托化、机械化、山地兵、海军陆战队和伞兵；平原另含装甲。按编制中获得效果的营种计算。登陆为国家层面的修正。不新增临时部署、购买、续费或计时经验。

## 资源来源与导出

本轮使用内置图像生成工具，未指定模型覆盖，也未调用CLI／API脚本。每个选用的背景或图标均有独立生成请求，完整提示词、原始输出路径、项目内源文件和SHA256保存在 `art/prompts.json`。选用12张原稿已复制到 `art/source/`，生成工具原件保留在原处。

背景按GUI目标尺寸缩放；图标采用Lanczos缩小并转换为RGBA DDS。技术导出不重绘背景、不移除背景、不改变图标颜色；创作由图像生成工具完成。单张32像素决议图标为单帧，分类画布52×40。透明原稿可有极弱的边缘颗粒；可见轮廓以alpha≥32测量，原稿像素保持完整。

`interface/sof_civilwar_art.gfx` 注册 `GFX_decision_sof_cw_*` 和 `GFX_decision_category_sof_cw_*`；决议只写 `icon = sof_cw_*`。`panel.dds` 保存生成的完整背景，`chrome.dds` 是独立透明边框／衬板层。
