# 十二种细分意识形态面板

用户确认显示当前全部12种路线：自由共和主义、保守共和主义、社会共和主义、革命社会主义、先锋社会主义、自由社会主义、法西斯主义、纳粹主义、法团主义、君主主义、威权主义、地方自治主义。

政治面板用12种独立颜色和图例显示这些路线，并标出当前执政路线。图例显示一位小数，悬停可查看所属大类、支持率及既有路线说明。0%路线仍列在图例中。饼图用100个可变颜色扇区，精度为1%；累计边界取整，末段闭合，避免出现99%或101%的圆。

## 支持率口径

游戏与既有存档仍保存共和、社会主义、法西斯、非同盟4种党派支持率，各党由一名现任代表选择细分路线。面板把一个党的实际支持率归入其当前领袖的路线；其他路线为0%。因此同时有正支持率的扇区最多4种，全部12种都可随领袖／路线变化进入饼图。它不虚构同一党内部的三派票数，也不把12种路线改为12个引擎政体。

执政党的路线直接读取当前领袖的子意识形态。反对党通过已招募人物和现任党派领袖检查识别，支持新创建的角色和运行时路线变更；过期、未招募和已被替换的角色不提供票数。无法识别的旧式匿名领袖采用该大类原有默认路线。无有效支持率时显示空圆与说明。

## 刷新与兼容

开局／读取存档时初始化，随后每天自动刷新。现有政体同步效果在原有马赛加成隔离条件之外刷新图表，因此红色马赛也能显示。暂停时可点击“政治光谱”右侧的小刷新按钮，无政治点数消耗。数据适配只写`sofzh_chart_*`显示缓存，不改变党派支持率、领袖、国策、政体条件或民族精神。

新图表替换本国政治面板里的原四类图表与图例；外交面板仍使用原党派系统。既有头像、领袖、选举信息、民族精神、阵营按钮及内阁控件保留。图例使用游戏原有中文位图字体缩放，避免增加字体依赖。

## 安装与检查

`python tools/package_ideology_panel.py`生成只含13个运行文件的补丁；解压后运行`install-ideology-panel.ps1`。安装器先验证原文件哈希并备份，再写入；有额外改动时停止。它保留已安装版本及两个描述文件，因此能叠加在当前4.4.0国策版本上。

`python tools/validate_ideology_panel.py`检查实际GUI、DDS、分类覆盖、既有逻辑保留，以及54组脚本解释情景。`python tools/verify_ideology_installer.py`在工作区目录执行真实安装器，验证成功安装、重复安装、冲突拒绝、包哈希／路径检查和失败回滚。完整仓库检查已接入这套审计。检查与布局预览不代表引擎已成功加载。
