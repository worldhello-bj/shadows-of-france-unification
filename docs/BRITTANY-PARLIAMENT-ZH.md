# 布列塔尼：议会、孤立防御与积极进攻

雷恩（REN）使用174项专属国策，其中116项为布列塔尼军事国策。参照本机1.19版美国的逐步动员、议会表决与原生决议面板，玩法核心是地方代表协商：支持有期限，拨款有条件，军备与对外行动须取得授权。

## 议会互动与各领域拨款

沙托与勒梅斯特初始提供35席、180日过渡支持。听证国策解锁后，协商花费25至35政治点，换取180日支持与对应临时支出修正。同一代表团不重复计票。每日雷恩专属钩子、家乡事件、改任和法案结束均重新计票。

普通法案要求51席，修订中立法、远征预算及全面动员要求66席，对外战争授权要求75席。每案花费30政治点、审议45日，同时只能审议一案。结束时复核多数、专题赞助人与威胁条件；失败或取消退回10政治点，不授予授权。

市政共和、工农合作、自治保守三条内阁路线互斥，分别要求对应代表团承诺及51席多数。组建责任内阁后启用共和政体；首脑分别为沙托、巴翁、勒梅斯特。

经济、陆军、海军、航空、科研和外交均有可实际运作的委员会拨款：

| 专项 | 主要收益 | 前置条件与代表团 |
|---|---|---|
| 经济 | 民用建设+12%、军工产出+8% | P15，沙托与勒梅斯特 |
| 陆军 | 攻击+6%、防御+8%、组织度+4% | M3及所选军事路线，巴翁与勒梅斯特 |
| 海军 | 船坞产出+10%、护航效率+8% | N2及港务法，勒戈尔热 |
| 航空 | 任务效率+8%、事故风险−8% | A2，巴翁与特雷曼坦 |
| 科研 | 研究速度+8% | E9及P9，勒梅斯特与特雷曼坦 |
| 外交 | 改善关系维持费用−20%、贸易评价+15%、政治点倍率+5% | D0及P20，沙托与勒戈尔热 |

每项35政治点、持续180日、冷却180日，均要求51席多数与独立政府。失去多数、必要代表团支持或政府资格会撤销拨款；改任及家乡沦陷同步复核。过期后须再次拨款，不能重复叠加。

完成地方议会国策后，可花费50政治点切换原代表与候补，每个代表团冷却180日。改任清除原有承诺与协商支出，重新检查候任者家乡，并撤销不再满足条件的专项拨款。新代表须重新协商，总席位始终为100。

## 孤立防御与积极进攻

116项军事国策包含28项重写的原有军事节点、16项共同整备，以及各36项的孤立防御和积极进攻路线。两个路线入口互斥，后续节点确实依赖所选入口。大部分军事节点21日，重点动员、船坞和路线收束35日；全树军事节点使用15种原创布列塔尼徽章。

孤立防御要求51席，发展树篱与河线防御、港口要塞、民兵储备、防空警戒和沿岸护航。入口提供本土防御+16%，附带计划速度与造船建设代价；末端追加本土防御+10%，保留进攻能力代价。

积极进攻要求66席、远征预算和前置中立改革，发展炮兵、运输、联合航空、登陆准备和远征补给。入口提供陆军攻击+6%、计划速度+10%、最大计划+6%，同时降低本土防御、民用建设并增加消费支出；末端强化攻击、计划与补给。主动战争仍另须75席战争授权和解除相应孤立限制。登陆项目采用1.19版的计划数及师数上限修正。

四阶段孤立限制逐级替换，不重复叠加。外部威胁指本国交战，或邻国交战／对本国拥有战争目标。全面动员另须35%战争支持。遭宣战时自动解除动员限制以自卫，和平后恢复此前阶段；议会已批准全面动员则保留解除结果。紧急自卫不会自动授予主动战争权限。

## 高于通用国策的强度

以2026年10月6日本地4.6.0模组的通用成熟阶段 g3 为基准（本分支保存八类冻结基准于 `design/brittany-generic-baseline.json`），八类专属永久机构的对应修正取130%：民用工业、军需生产、步兵、参谋、科研、船坞、航空支援、防空。逐项对照见 `docs/reports/brittany/balance-comparison.json`。例如通用民用建设+20%对应布列塔尼+26%，通用步兵攻击+12%对应+15.6%。这表示对应机构数值提高30%，不等于整国胜率或所有奖励提高30%。

共同军事研究奖励也加强为125%、两次使用；新增路线研究奖励补充专项发展。经济和船坞重点国策提供两次本地建设拨款，每次独立检查拥有、完整控制和容量，没有合格厂址则提供25政治点。科研槽仍受工厂数、槽位上限与一次性标记约束。路线、内阁与预算继续保留真实的政治和生产代价。

布雷斯特（168州）、洛里昂（208州）船坞及本地制造商保留厂址条件和专精。对外协约由对方事件选择接受或拒绝并复核条件。领土整合继续使用现有付费、计时占领制度。

## 家乡沦陷、攻下与收复事件

家乡按政治活动基地映射到模组州，覆盖188、168、162、165、179、198、200七个地区。它们不一定是出生地；目前是州级控制事件，并非精确到市镇所在省份的战斗判定。

七地各有沦陷、首次攻下、再次收复三类事件，共21个。初始化只记录已有控制状态，不制造开局攻占事件。雷恩直接控制，或盟友控制雷恩自有领土，均视为家乡可联系；盟友代守不会被判为敌军沦陷。

失去联系时，只清除现任且政治基地在该地的代表团承诺与支出，暂停其协商，并重计多数和委员会拨款。攻下或收复恢复协商资格，需要重新付费取得支持。未在任人物的地区变化不会撤销其他现任者的席位。

沦陷事件可选择花费25政治点维持流亡代表团，暂时增加消费支出，恢复正常付费协商资格；也可确认损失后改任其他候补。弹窗支付选项再次检查家乡仍不可联系，避免收复后误收费。每地区14日通知冷却，控制变化仍及时更新。反复易手不赠送核心、吞并、政治点或人力。

## 原生决议界面与预览

原生 scripted GUI 置于布列塔尼议会决议分类，参考美国国会面板。原创深青底纹、金色细框、白鼬印记、100席半圆图和六张议员卡，分页为“议员协商”“法案进程”“军事纲领”“委员基金”。议员名称会随候补切换，席位显示来自实际支持变量。协商按钮检查实际政治点、政府资格、听证、暂停和承诺状态后才扣费。
