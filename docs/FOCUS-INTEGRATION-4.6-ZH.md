# 4.6.0 政治界面与移植国策融合

截图中的放射杂线来自旧政治面板的旋转分段纹理。改为原版 `GFX_political_chart` 饼图，保留四类政党真实支持率；右侧只显示四个党派目前代表的细分路线。12种路线与各自玩法继续存在，暂停时可手动刷新。图例在民族精神上方，设裁剪范围，清除旧100段缓存和两幅旧纹理。

历史内阁的隐藏清理效果仍会替换同职务成员、设置90天冷却，但任命提示不再列出所有候选人的移除加成。国策完成、政体符合且人物未退役时才显示可招募历史部长；已经任命的人保留在列表中。强力加成、125政治点价格与实际冷却保持原值。

修正两处历史人物头像 token 的引号／后缀错误，补齐10名人物的原生领袖角色；12项领袖国策先确保招募成功，再进行角色和政体操作。效果提示明确显示领袖、政体与免费行政首席任命，内部角色清理隐藏。40名部长的解锁和替换仍使用实际国策与统一内阁槽位。

4.5.1旧档在启动与每周国家脉冲中补回缺失的已完成路线领袖，只在当前政体仍匹配时处理；不重发政治点、制造商或工业奖励，不替换已付费任命的行政首席，也不把后续政治选择改回去。为旧故障档补回人物可能需要游戏加载后经过一次周脉冲。

国策树节点、独占图标、资源、初始工业和制造商文件保持原字节。这次解决截图中的布局、任命提示和人物奖励融合；不会把旧档国策重新完成一遍。

已有4.5.1使用 `python tools/package_focus_integration.py` 生成窄补丁。关闭游戏，解压后运行 `install-focus-integration.ps1`。安装器核对每个文件的旧／新哈希，备份后仅写入清单文件并删除两幅已审核的旧贴图；其他改动会使安装停止。两个描述文件只更改版本号，保留工坊ID与封面。
