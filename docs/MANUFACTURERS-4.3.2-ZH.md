# 4.3.2 制造商八层成长与强化

20家地区制造商全部扩展为8层、两条可兼修成长线、每家16项特质，共320项。游戏实际使用两列8行，纵坐标0至7；第8层需要同一成长线的前7项，保留原生组织经验、等级和特质点。第3–5层需要该国先进工业国策，第6–8层需要军工复合体或对应专属建设国策。

原版参照来自本机1.19的 `00_generic_organization.txt` 和 `FRA_organization.txt`：步兵坦克模板15项、机动坦克12项、火炮13项、摩托化/机械化15项；常见单项可靠性、速度、穿甲或攻击为5%，部分突破或法国专属特质为10%。原版模板本身通常只有3–4行，本版按要求增加到8行；没有把“8个节点”冒充8层。取材模板、示例特质及文件哈希见 `design/vanilla-mio-growth-reference.json`。

| 项目 | 4.3.0 | 4.3.2 |
|---|---|---|
| 组织成长 | 4项特质、实际2行 | 两列8行、16项特质 |
| 起始主打性能 | 4–6% | 8–10% |
| 满成长主打性能 | 通常8–10% | 通常38–40% |
| 廉价装备线的造价 | 满成长−6% | 满成长−25% |
| 专项科研 | 10% | 起始15%，末期20% |
| 组织经费获取 | 无额外成长 | 起始+25%，成长后合计+50% |
| 并行任务容量 | 2 | 起始3，末期4 |
| 承接生产线 | 效率增长+3%、资源需求−2% | 生产成本−12%、效率上限与增长各+12%、资源需求−8% |

巴黎满成长装甲+40%、可靠性+16%，速度−2%的原有代价保留；波尔多对舰攻击+40%、航程+16%，机动性−3%；科西嘉可靠性+40%、防御+16%，原有对人杀伤−2%的取舍保留。图卢兹侧重航程、梅斯侧重穿甲、里昂侧重燃油消耗，廉价器材路线侧重装备造价。所有20家企业的完整合计见[制造商名录](REGIONAL-MANUFACTURERS-ZH.md)。

装备造价与生产成本是两个不同的原生指标。全部特质的合计只作用于组织承接的装备与生产线，不授予全国攻防修正。第戎的防空及装甲性能对拥有相应基础属性的列车型号生效，普通列车仍能受益于生产线加成。

组织ID和旧trait_1至trait_4保留，旧点选特质通过相同token继续解析；新增特质使用trait_5至trait_16，不重置组织等级、已有点数或国家工业进度。无AAT时仍使用传统设计商，科研和起始装备工艺同步加强，但没有原生组织成长界面。

本轮升级包只覆盖制造商组织、传统设计商和中文本地化三份文件，覆盖前校验4.3.0或已升级内容的哈希并生成备份；人物、历史、国策、美术和其他并行编辑保留。共享源码中的马赛4.3.1版本号不在此处改写，独立候选包从已提交4.3.0基线单独构建。

验证覆盖真实8行布局、320项特质、最长前置深度、旧token保留、分层工业门槛、DLC双路径和满成长数值预算。源码及安装验证不等于游戏实测；原生详情页滚动、真实旧存档与更新装备设计的结果仍待引擎验收。
