# 法兰西之影：统一战争

当前源码版本：**6.0.11**。适配《钢铁雄心 IV》**1.19.***。

`mod/` 是完整游戏运行目录，直接使用这份源码，无需叠加历史补丁。

## 6.0.11 修复

重新设计法兰西政府界面为国家档案式治理面板：使用墨蓝、纸白、黄铜边框、法国三色旗与新雕刻页眉。四个独立分栏为统一筹划、战役指挥、地方议会和国家工程；撤去重复的政党、民族精神总表及内阁招聘镜像。历史内阁仍通过原生政治界面运作。

统一地图与谈判合同继续保留；挑战与强制执行移到战役指挥的统一行动令，沿用原有费用和政治门槛。议会保留100席、议员游说、法案和战争授权。新增交通命脉、全国军备、联合参谋部、统一财政四项国家工程，提供立项、50日推进、追加投入、战争暂停、撤销与一次性验收。旧州重建项目保持原规则并单独列入工程页，旧界面状态会迁移到统一筹划。

## 6.0.10 修复

修复法兰西政府界面的分栏重叠与内容覆盖问题：六个内容分栏通过 parent_scripted_gui 明确挂载到政府主控制器，八个内阁职务页挂载到内阁分栏；分栏背景铺满可用区域，修正重复扣减的高度。主选项采用固定间距的滚动标签栏，狭窄界面也能访问全部选项。内阁候选页保留横向和纵向滚动。

民族精神卡片分别展示基础精神、制度积累和两者合计。国策完成后强制刷新动态修正，消除显示立即更新而实际收益等到下一天才更新的差异；读档后的首次同步也会刷新。制度积累的原生说明列出当前六项真实修正。保持既有收益强度、国策 ID、完成标记和领取记录。

## 6.0.9 修复

科西嘉国策树恢复意大利式的分区与相对布局：工业、陆军、空军和海军分别成列；共和国、统帅、委员会政治路线纵向分流；大陆外交和全国统一位于后续区域。保留国策 ID、前置、互斥、可用条件和本地区建设。修正合并航母项目与后续海军国策处于同层的问题，调整全国战略延续的上下关系，并补充路线快捷入口。

继承的意大利动态修正也统一为整数步长，补上68项具体长期奖励提示；旧变量在启动和首次每日同步时整理，保留国策完成及领取标记。民族精神与制度成长继续采用每项主能力+2%、基础10%／20%／30%、地区优势12%／24%／36%、副项5%／10%／15%的方案。旧存档实际读档和游戏内界面尚未验收。

## 6.0.8 修复

本次修复国策收益与界面显示。1,843项地区及共享国策均有明确的长期收益提示。每项国策永久增加本方向主项2%；民族精神基础为10%／20%／30%，地区优势方向为12%／24%／36%，副项为5%／10%／15%。取消原先低于4%的递减收益。党派政策另列真实的长期加成，全国战略、生产与作战政策强化为10%主档。

修复统一政府窗口各分栏与内阁职务页互相叠压的问题；国家精神卡片显示基础与累计的实际合计，内阁卡片直接列出修正。补齐党派执政条件及支持率修正的中文名称，常规奖励采用2或5的整数倍。国策说明压缩，减少原生详情窗文字溢出。

## 6.0.7 内容

21 个大区均接入专属国策树，补全利穆赞／利摩日路线。精简繁密分支，按各大区的地理和产业本土化名称、描述与建设效果；扩展地区党派路线，将全国统一与战后重建作为叙事主线。

政府界面整合为带法国三色旗的六个分栏，修复布列塔尼议会显示。国策奖励更多采用分阶段民族精神；扩充历史人物内阁、28 座城市的占领／失去／夺回差分新闻，以及 49 项施政事件和 49 项相关新闻。新增 12 张原创事件插图，制作 24 张原生纹理并接入 126 个事件配图定义。

## 安装

Steam 工坊条目：<https://steamcommunity.com/sharedfiles/filedetails/?id=3813153193>。

保存并关闭游戏，下载或克隆本仓库后，在 PowerShell 中运行 `./install.ps1`。安装器直接复制 `mod/`，并备份现有目标目录。

更新已有工坊目录时，使用 `./install.ps1 -TargetPath '你的工坊模组目录'`。原有工坊 ID 会保留。游戏存档不在安装范围内。工坊版应单独启用；详细说明见 `mod/README-ZH.md`。
