# 法兰西之影：统一战争 6.0.10

从一座城市出发，在四分五裂的法国争取全国统一，决定新法国的制度与重建道路。本模组包含地图、国家、人物、国策和中文内容，可独立启用，无需额外安装母模组。适配《钢铁雄心 IV》1.19.*。

## 6.0.10 修复

修复法兰西政府界面的分栏重叠与内容覆盖问题：六个内容分栏通过 parent_scripted_gui 明确挂载到政府主控制器，八个内阁职务页挂载到内阁分栏；分栏背景铺满可用区域，修正重复扣减的高度。主选项采用固定间距的滚动标签栏，狭窄界面也能访问全部选项。内阁候选页保留横向和纵向滚动。

民族精神卡片分别展示基础精神、制度积累和两者合计。国策完成后强制刷新动态修正，消除显示立即更新而实际收益等到下一天才更新的差异；读档后的首次同步也会刷新。制度积累的原生说明列出当前六项真实修正。保持既有收益强度、国策 ID、完成标记和领取记录。

## 6.0.9 修复

科西嘉国策树恢复意大利式的分区与相对布局：工业、陆军、空军和海军分别成列；共和国、统帅、委员会政治路线纵向分流；大陆外交和全国统一位于后续区域。保留国策 ID、前置、互斥、可用条件和本地区建设。修正合并航母项目与后续海军国策处于同层的问题，调整全国战略延续的上下关系，并补充路线快捷入口。

继承的意大利动态修正也统一为整数步长，补上68项具体长期奖励提示；旧变量在启动和首次每日同步时整理，保留国策完成及领取标记。民族精神与制度成长继续采用每项主能力+2%、基础10%／20%／30%、地区优势12%／24%／36%、副项5%／10%／15%的方案。旧存档实际读档和游戏内界面尚未验收。

## 6.0.8 修复

本次修复国策收益与界面显示。1,843项地区及共享国策均有明确的长期收益提示。每项国策永久增加本方向主项2%；民族精神基础为10%／20%／30%，地区优势方向为12%／24%／36%，副项为5%／10%／15%。取消原先低于4%的递减收益。党派政策另列真实的长期加成，全国战略、生产与作战政策强化为10%主档。

修复统一政府窗口各分栏与内阁职务页互相叠压的问题；国家精神卡片显示基础与累计的实际合计，内阁卡片直接列出修正。补齐党派执政条件及支持率修正的中文名称，常规奖励采用2或5的整数倍。国策说明压缩，减少原生详情窗文字溢出。

## 安装与启用

工坊条目：https://steamcommunity.com/sharedfiles/filedetails/?id=3813153193

订阅后由 Steam 下载更新，重启启动器并在播放集中启用“法兰西之影：统一战争（独立中文版）”。本整合版应单独启用，停用旧的“Shadows of France: Updated Version”及其独立汉化，游戏语言选择简体中文。推荐新开档，可选择区级政权或 21 大区政权剧本。

源码版在仓库根目录执行 `install.ps1`，安装器复制完整 `mod/` 并备份现有目录。完整地图的 `replace_path` 必须保留，它们用于替换基础游戏世界的数据；此模组仍需钢铁雄心 IV 基础游戏。
