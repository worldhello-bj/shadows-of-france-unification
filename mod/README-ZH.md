# 法兰西之影：二十国策与通用内战界面 3.2.0

本版本包含20国1,408项国策，新增通用内战决议GUI、生成背景与11种原创透明决议图标，展示阶段、地方秩序、统一进度、法国邻接势力和永久地形经验。详见 `docs/CIVILWAR-GUI-ZH.md`。这是经过静态与模拟检查的候选包，尚未完成引擎和旧存档验收。

这是包含原版地图和全部运行素材的独立整合版。法国及邻国地图、国家与人物、旗帜、历史、两种剧本，以及现有中文、矿业和统一战争扩展都已合并到一个模组。

## 安装与启用

将本压缩包完整解压，在解压目录运行：

`powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1`

安装到 Windows 文档下的 Paradox Interactive/Hearts of Iron IV/mod。自定义用户目录可传入 `-UserDataPath "完整路径"`。安装脚本核对全部文件，更新已有独立版时先备份；它不会要求安装或查找任何工坊母模组。

也可手动将 `shadows_of_france_unification.mod` 与 `shadows_of_france_unification` 文件夹一起放入 mod 目录。二者必须在同一层。

重新打开启动器，在播放集中启用“法兰西之影：统一战争（独立中文版）”，停用旧的“Shadows of France: Updated Version”和“Shadows of France: Updated Version - 简体中文”。这三个版本都包含同一张地图和同一批国家，合并版应单独启用。游戏语言选择简体中文。

建议新开档，分别体验328个区级政权开局、21个大区政权开局。已有1.4.0存档的内部国家、州、国策与单位ID沿用；存档能否迁移尚未在游戏内测试。

安装仅复制独立版本文件，启动器播放集和游戏设置由用户选择。卸载时停用独立版，再移除 `shadows_of_france_unification.mod` 和 `shadows_of_france_unification` 文件夹。

## 独立整合方式

版本号为2.9.9，内外描述文件采用独立名称和目录，无父模组 dependencies 与原工坊 remote_file_id。保留原地图模组的全部 replace_path，因为它们负责用法国地图的数据替代基础游戏世界的数据。独立版仍以钢铁雄心4基础游戏为运行环境。

现有1.4.0运行脚本和素材按哈希吸收，之后叠加独立版意识形态扩展和1.19兼容修复。所有编码规范化、通用定义更新和人物子类型修正逐项列入清单，未涉及的原有运行文件逐字节保留。中文文件统一放入 localisation/simp_chinese/replace，避免同一版本重复装载中文键。编辑器源文件不放入游戏包。

原包 map/rivers2.7z 实际为5632×2048、8位索引BMP，使用与基础游戏一致的河流调色板；独立版按游戏读取的名字收录为 map/rivers.bmp，图像数据逐字节保留。
