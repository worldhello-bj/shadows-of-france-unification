# 开局50国整合修复 · 2.9.3

新开区级剧本，开局推进一小时可收到整合确认。也可在决议 → 开局版图设置 → 随机整合法国地区：50个现存国家执行，确认“开始随机整合”后生效。取消保留机会。1936年1月8日前可用，全局一次。大区剧本只有31个国家，无需减少。

原循环混用了长形式var字段与value比较运算符；改用本机原生文档的value = 512、compare = less_than。旧检查器错误地假定这一混用形式表示小于，本次修正检查器并加入旧代码零次执行的回归案例。该诊断和验证依据本机脚本文档及独立模拟，尚未启动游戏确认。

先统计现存国家，循环最多尝试512次；每次随机选择可吞并的法国AI政权及其合法邻国。只有吞并后供体确实不再存在，才记录合并并扣减剩余数；结束后重新逐国统计。玩家、巴黎、科西嘉、外国政权和孤立海岛受保护，吸收州成为核心，人口、资源与建筑保留，不转移旧部队。

全局已使用标记在至少一次实际吞并之后才设置。旧版若留下已使用标记，但合并次数为0且记录仍多于50国，原执行玩家在同一开局窗口内可以重试；已成功执行及过期开局仍不解锁。入口显示与执行条件分开，国家数不足会显示具体条件，不再直接隐藏分类。2.9.4已移除和平限制，法国及外国战争均不阻止整合，供体和接收国也不要求处于和平。

结束事件显示实际次数与现存国家数；game.log记录[SOF random50]的merges、remaining、attempts。开局提示只调度一次，没有每日或每周轮询。旧的RANDOM50-MAP-ZH.png是规则模拟示意，并非实机截图。安装包脚本和文件哈希通过审计，实机结果仍由玩家启动验证。
