# 玩法奖励 · 二十国首版 3.0.0

18个新专属树采用地方政务、特色产业、军队教范与三条互斥政策。巴黎和科西嘉保留原有路线并各增加14项。各系列精神有初建、整备、成熟三档，只保留最高档；正式地方登记沿用2.13的费用、顺从、抵抗和连续控制条件。

新树的军队教范成熟阶段：陆军组织度+4.5%、组织度恢复+6%、陆军经验获取+8%。公共服务成熟阶段：每日政治点+0.05、稳定度+4.5%、工业修复+6%。产业协约依地方类型提供有限的工业产出、效率、船坞建设、消费品、科研或燃料支持，具体数值见游戏提示。政治路线带有稳定度、消费品、动员或政治点之间的取舍。

通常一次工程建设一个设施，只落在本地实际拥有并控制的州；已达到设施容量时取得替代政治点。新增科研槽只发放一次，总槽位达到5时提供50政治点替代。地方装备订单支付45政治点及对应步兵装备，按180或240天冷却；基础财政与运输合同仍是有时限的付费决议。

## 永久地形经验

| 类型 | 追加修正 |
| --- | --- |
| 山地 | 进攻+3%、防御+3%、移动+2% |
| 渡河 | 进攻+3% |
| 城市 | 进攻+3%、防御+2% |
| 两栖登陆 | 登陆进攻+3% |
| 森林与丘陵 | 两种地形进攻各+2%、防御各+3% |
| 平原 | 进攻+2%、移动+3% |

五类地形训练作用于步兵、摩托化、机械化和三种特种步兵；平原项也作用于装甲营。师修正按编制加权。两栖项使用原生登陆条件修正，作用于参加登陆的部队。不能将这些数值解释成无条件增加全军最终伤害。

同类只取得一次，不同类型可并存，时间推进和法国统一不会取消。九个旧临时部署定义保留为无效果的旧档兼容入口；授予与读档迁移使用同一组永久标记和隐藏科技。已到期部署依据可读取的已完成国策恢复。新旧树替换后的旧档可读取性仍需实机检查，推荐新开档。

民族精神“地方作战经验”与同名原生决议分类汇总已掌握类型。没有每日新增遍历；迁移在启动时运行。登陆计划数与每计划师数沿用已验证的2.12.1兼容修复。
