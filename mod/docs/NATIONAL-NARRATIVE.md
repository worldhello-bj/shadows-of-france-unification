# 大区作为法国统一事业的起点

大区国策以争取法国全国领导权、结束割据与建立统一国家为目标。地区产业、议会传统、地形和军事力量分别成为国家方案的基础。地方建设按实际地域实施，国策名称、主干叙事和战略收益面向全法国。

21个大区各追加五个70天的全国里程碑：国家战略、成组战略生产、全国战线、建国秩序、国家重建。它们分别接入既有全国使命、全国会议、中央或联邦宪制与战后重建。新增线路不授予战争许可，不降低法国全境统一要求。统一后可跳过战争筹备，避免阻挡重建。

战略生产在完整整合的本区建设两座民用与两座军用工厂；布列塔尼、卢瓦尔河地区采用一座民用、一座军用与两座沿海船坞。工程逐项检查核心、拥有、完整控制和容量，满容量时逐项给予财政和研究替代。全国战线按海权、航空或陆上战略分别提供经验、运输船、航空研究或卡车。各阶段都有独立一次性记录。

统一前持续政策提供政治、工业与军事统筹收益，并按地区国家方案追加专业收益。战略生产加成要求本区仍完整统一；建国后战争阶段收益退出，完成国家重建后改用和平工业、科研与行政整合收益。

十个党派的既有40项续篇ID和领取记录保留，叙事改为各党派的全国国家方案。续篇须取得既有全国使命，最后的党派建国纲领须以全国会议为基础。生产方向改为两期建设，运输方向补充全国动员车辆；仍共用一次建设拨款，不能换党重复领取。
