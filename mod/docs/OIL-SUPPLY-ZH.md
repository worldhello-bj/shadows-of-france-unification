# 适量石油补充 · 2.11.1

法国基础石油由190增至253，增加63（约33.2%）。21个大区的主供给点由6改8；各大区人口第二多的州作为次供给点，由1改2，共42州。分布在全国而非集中于某个地区。这些数量是地方储备、炼化和进口集散的虚构平衡抽象，不能作为1936年真实油田或产量引用；贸易法、资源开采和燃油炼化仍按游戏机制计算。

此前的煤钢铝、橡胶钨铬，低人力编制，美国式陆空军AI和和会吞并倾向保留。新开局自动生效。旧档重启后在“法国资源与城镇”执行免费“补充石油供给”；未做完上一轮资源更新的旧档会先补齐上一轮内容，再加本轮石油。资源增量采用一次性标记，保留国策开发所得资源，重复执行不会再增加。
