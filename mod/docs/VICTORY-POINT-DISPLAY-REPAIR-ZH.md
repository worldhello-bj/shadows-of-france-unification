# 小胜利点显示修复 · 2.11.3

实际游戏日志有563条“set victory points takes 2 parameters”错误，与323州的563个多点定义块逐一对应。此前静态校验按成对数字读取，错误接受了一个victory_points块里的多组数据；游戏只接受一个省份ID和一个点数。

例如安德利州原先为victory_points = { 10386 3 2871 3 }，现在分为victory_points = { 10386 3 }和victory_points = { 2871 3 }。563个错误块包含1491处点位，其余374处原本采用正确格式；修复后全部1865处均为单点定义。328座首府及1537处次级城镇的位置、点数和中文标签保留，城市文字仍按现有缩放距离显示。

新开局直接载入全部点位。已有存档不会重新读取州历史：重启游戏、载入旧档，在“城市标记修复”执行免费的“修复小胜利点显示”。该决议使用独立完成标记，因此不会被旧版本的“已经更新城镇”标记挡住；只赋值1537处次级城镇，重复调用不累计分数。新开局已自动标记完成；没有新增定期扫描。

源生成器一并改为逐点输出，新增校验要求每个定义块恰好有两个参数，核对点位全集、中文标签及旧档决议。开发记录见zh_work/vp-display-repair-pass，实机检查结果单独记录。静态通过不等于地图已目视确认。
