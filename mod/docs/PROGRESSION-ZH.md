# 专属树地区晋级与成长 · 2.8.2

巴黎和科西嘉各新增六项地区发展国策：区级行政→省级组织→行省体系→大区协约→邦国机构→国家制度。门槛依次为完整拥有、完全控制1、4、7、13、26、51个法国州，外国州和仅占领州不计入。巴黎共66国策，科西嘉共58国策。国家级机构不等于法国统一；最终建国的339州要求继续使用。

行政、民生、军工和交通工程各有初建、整备、成熟三阶专属精神，数值为通用同阶的1.15倍。已持有精神时直接swap；跳级和旧通用精神的转换只替换实际持有的等级。低级补做不降级，同级重复不叠加。

巴黎民生系列由塞纳工业、战争债券和工业计划推进；军工系列由统一工场订单、联通兵工厂和洛林协作推进；交通系列由巴黎车站、后勤仓库和电网协作推进。中阶项目要求完成省级组织，成熟项目要求完成邦国机构。原有地区建筑奖励保留。科西嘉十八项对应项目与六级晋升调用同一套专属成长精神，既有岛屿和登陆前置条件保留。

根据2.8.1实际游戏日志与本机原生定义，经验奖励统一纠正为army_experience、navy_experience、air_experience，并补齐巴黎法兰西岛战争目标的调用。未启动游戏实测。建议新开局验证新增晋级路线；旧存档已完成国策不会自动补发奖励。
