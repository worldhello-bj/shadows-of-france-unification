# 大区国策阶段合并

本轮检查全部21个大区，优化19个地方树及党派、马赛公共分支。合并179项准备节点，调整361个节点中的小额经验或低倍率研究奖励。布列塔尼和利穆赞地方树沿用前次版本；利穆赞加载的党派附加树跟随本轮公共调整。

参考本机日本国策树的主题分区、集中里程碑和明确战略选择，将相同领土、时间及执政资格的连续准备项，或同级同终点项，合并为阶段计划。原有互斥路线、地方机制与历史事件保留。政治入口下的部分工业和军事基础准备获得独立入口，后续阶段仍受原始资格限制。大型树中的历史路线和互斥选择保持独立，未并入准备阶段。

合并后的阶段集中领取原有收益，建设、科研槽、人物及事件仍执行各自原始限制。正值且低于25的陆海空军经验提升至25；不带提前研究减免且正值低于75%的研究加成提升至75%。合并的普通准备阶段通常为35日，工程和重要事件阶段保留相应门槛；部分原耗时较长、只有小额直接奖励的准备项缩短为35日。

巴黎增加互斥的两项35日预算：首都防御与阵地优先，提供本土防御和工事建设优势；机动军与主动进攻优先，提供组织度、攻击和军工生产优势。两者各给25陆军经验，并承担相应建设取舍。另修正贝桑松、克莱蒙费朗、第戎、里昂、南特共10项外交节点的国家存在条件，目标国家与其他资格不变。

退役国策ID保存于不加载的兼容定义中。原领取标记和事件ID保留，决议、党派纲领及军工组织引用同步。迁移按既有完成与领取标记保护已赚取收益，保留存续国策的完成记录，不补发合并后的工厂、科研或经验。此处是源码与模型验证，旧档实际行为仍需战役验收。

本轮源码、资源引用、分支可达性及防重复领奖模型检查通过。布列塔尼与利穆赞回归检查通过。68个安装文件逐项与源码核验一致，第二次初始引擎加载检查未发现新增诊断；整模组仍存在基线已有诊断。验收范围为源码、安装和初始脚本/资源加载，未实测战役、旧档和游戏内国策界面。

源码预览包含全部21个大区及党派切换，保留当前坐标、偏移和依赖线；静态图与节点中心检查通过。预览脚本语法通过检查。本地文件协议被浏览器工具策略阻止，未完成浏览器交互验收。源码预览不代表游戏内布局验收。
