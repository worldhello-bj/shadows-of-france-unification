# 占领治理、地方整合与游击战 · 2.13.0

修正百分比单位错误：原占领奖励抵抗目标-5/-7.5/-10实际为-500%/-750%/-1000%，现为-2%/-3%/-4%。占领、行政、内阁与巴黎相关精神的每日顺从加成降为原来的20%，顺从增长速度加成降为40%，驻军需求与抵抗伤害减免降为50%；其他正常抵抗目标减免降为25%。占领法和原版抵抗引擎保留。

地区成立改为提供领土宣称，整合国策提供行政授权。月度自动核心、巴黎扩张行政直接核心、科西嘉与巴黎地区直接核心、全国统一时批量核心全部取消。开局随机50国的核心属于剧本初始化，保留；已有存档的核心也保留，不倒改玩家过去的领土。

每个非核心法国州连续控制180天、顺从至少60%、抵抗低于20%且国家和平独立后，可支付35政治点、150步兵装备和25支援装备，进行120天正式整合。完成时再次检查全部条件。失去控制和开战会取消；不能利用改旗、成立地区、完成国策或重复决议绕过门槛。地方项目可并行，但同州不能同时执行多个治理项目。

每月刷新一次地下组织。35%以下为潜伏组织（抵抗目标+6%、顺从增长速度-10%、驻军需求+10%）；35%起为活跃游击（目标+10%、驻军需求与伤害+20%、资源-10%、非核心补给负担+10%）；60%起为广泛叛乱（目标+15%、驻军需求+30%、伤害+35%、资源-20%、非核心补给负担+20%）。三个档位互斥，降下抵抗后也会降档，成为核心或换控制者时清理。

活跃游击州每月20%概率发生一次袭击，广泛叛乱州40%。破坏0.3单位基础设施，若有兵工厂再破坏0.25单位；顺从-1、抵抗+2个百分点，分别损失75/150人力与60/120步兵装备。原生驻军损失同时正常运行。通知最多90天一次，不逐州弹窗，不生成无限叛军师。

民生重建：35政治点+100步兵装备+25支援装备，45天后顺从+5、抵抗-4，180天顺从速度+15%、抵抗目标-2%，每州180天冷却。地方调解：25政治点，30天后顺从+3、抵抗-8，180天抵抗目标-5%、驻军伤害-10%，每州180天冷却。清剿：25政治点+300步兵装备+500人力，45天后抵抗-12而顺从-3，90天免额外脚本袭击、120天冷却；它没有取消原生驻军伤亡。

敌后输送：交战时针对仍由敌国控制且不是敌国核心的法国州，支付30政治点+250步兵装备+25支援装备，30天后抵抗+8、顺从-3，每州180天冷却。控制者改变、战争结束时不会误伤友军。AI同样支付费用，库存不足不会挪走紧缺前线武器。

巴黎和平归并只对被归并方的州给予10点顺从和5点抵抗减免、180天调解协议，仍要遵守控制时间和核心登记要求。旧档在下次月度更新初始化现有非核心占领区；完整体验建议新开档。图标、资源、战线AI、海域与胜利点修复保持2.12.0。
