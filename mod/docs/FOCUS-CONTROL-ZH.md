# 国策领土条件修复 · 2.9.5

巴黎树取消60项国策重复的“拥有并完全控制巴黎”门槛。政治、科研、参谋与普通工业分支按前置国策推进；仅巴黎守备部队的具体编成地点和在巴黎召开的全国会议要求控制巴黎。普通工业建设优先选择法兰西岛/科西嘉，失去原有基地后在其他控制州继续建设；矿区工业建设仍落在相应的真实矿区。

专属行政晋级采用与通用树一致的实际控制州数：基础行政无额外领土门槛，后续4、7、13、26、51州。战时占领和境外控制州都计入，不重复检查法国州白名单或法律所有权。完成前置阶段后即可发展，民族精神仍按实际持有等级swap，不降级、不叠加，专属同阶强度保持1.15倍。

洛林、北方煤田、阿尔萨斯、瓦尔铝土矿专属项目按州的军事控制权开放，无需和会吞并，也不要求占领该州每一个省份。科西嘉洛林条件和兵工落点修正为94、98、116州，阿尔萨斯修正为127、214、217州，与既有资源核验数据一致。109州是诺曼底铁矿，不能代替洛林；98州是洛林铁矿，不能代替阿尔萨斯。

通用矿区开发也改为控制区选择，开工条件、奖励落点和已开发项目的跳过条件使用同一规则。州级开发标记沿用，夺取已经开发的矿区不会重新刷资源或工厂。资源普查无需先占领矿区；合成橡胶建设不要求处于法国州白名单。矿区奖励在控制州落实，合同精神随矿区控制权变化；原有资源储量、军事奖励数量和强度保持不变。

法兰西岛与科西嘉地区整合要求完整控制相应地区，但不要求法律所有权；核心效果同样作用于完整控制的地区。科西嘉岛屿统一、跨海使命和全国会议取消额外和平门槛。最终宣布统一法国仍沿用339州与和平条件，外交合并仍核对合法拥有者。仅修改国策与对应效果，不增加周期性扫描。

安装后重启游戏；旧档未完成的国策使用新条件，已完成国策不重复奖励。独立测试区分所有者与控制者，覆盖占领、失去控制、夺取已开发矿区、等级swap、实际资源与建筑落点。未代替玩家运行游戏。
