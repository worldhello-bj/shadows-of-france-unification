# 战时随机整合与科西嘉海运 · 2.9.4

随机50国整合已移除全局法国和平检查，以及供体/接收国的has_war = no筛选。开局存在战争、玩家正在参战或相邻AI正在参战，均不因战争状态被禁止。仍只允许1936年1月8日前执行一次，并保留玩家、巴黎、科西嘉COR、邻国及其他既有保护条件。已经投降或作为附庸的政权仍不属于合法接收国。

科西嘉港口数据与实际地图逐像素核对：485州6243省、491州18040省、499州18179省、504州18258省、509州18333省都拥有4级港口，均属于相应州并与有效海洋省份相邻；五个港口都能经海洋连接到大陆。原始五国历史则全部set_convoys = 0，没有开局商船。

新开局为AJC、BST、CLV、COR、SRT各配置20艘运输船，并标记已获得初始海运配置。新档直接使用原生贸易界面；正常购买仍消耗可用民用工厂，受出口方库存、航线、禁运及原生海军封锁影响。原有国策提供的商船保持其数量，不改资源储量、贸易价格或全世界贸易规则。

旧存档重启并重新载入后，可在决议 → 科西嘉海运 → 补发开局商船领取20艘运输船，只能领取一次。领取会增加现有运输船，不会把已有数量重置为20。没有拥有并完整控制科西嘉州、已经投降、AI国家、岛外原始国家和已领取者均不能使用；新档已经领过初始配置，也不会出现补发入口。该兼容入口不限开局日期，可修复1937年等旧存档。开局随机整合的时间窗口仍按原规则限制。

安装时游戏可以保持打开；文件更新后需重启加载新版。修改国家历史不会自动改变已有存档，因此旧档必须使用补发决议。此修复依据已确认的开局商船缺失；购买按钮灰色也可能有其他原生原因，若补发后仍无法购买，需要根据贸易提示和game.log进一步核实。脚本、真实省份接壤、海洋连通及新旧存档的标记/数量规则均经过独立检查，未替玩家启动游戏确认交易。
