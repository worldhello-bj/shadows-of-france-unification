# 党派国策的地区续篇

十个既有党派分支各追加四项35天国策：地区议程、互斥的生产订单与公共运输、项目验收。每局选一条投资路线，实际延长105天。69项既有党派国策的ID、前置、坐标与奖励保持原样；新增部分共有40项。按历史党派覆盖范围接入20个大区，布列塔尼继续使用地方议会机制。

建设落点对应原大区的固定地点：瓦朗谢讷金属加工、敦刻尔克修船、利摩日陶瓷、圣纳泽尔船厂、米卢斯精密制造、图卢兹航空工坊等。莱茵河港改善使用基础设施。项目要求拥有、完整控制且是本国核心；工厂有容量检查，基础设施不超过5级。容量不足时兑现明确的研究或车辆替代奖励。

党派政策按政治主张区分：共产党重工人监督，SFIO重就业协议，激进党重市镇信贷，USR重技术统筹，PUP重合作社，民主联盟重招标审计，共和联盟重防务订货，人民民主党重家庭工场，UPR重阿尔萨斯双语学徒制，多里奥组织重巴黎街区训练。各地区另有产业与运输加成。

所有党派共用一次建设拨款，防止换党重复建设。首次项目验收的工业研究奖励也共用一次；每个新节点的奖励有独立领取记录。持续政策只在相应党派执政、政府类型匹配、未投降且保有选定地点时生效；每日重新计算，避免换党叠加。复归执政可以恢复政策，不能重复建设。
