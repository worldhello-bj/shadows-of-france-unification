# 铁路与补给 · 2.9.9

新增2282段相邻省份铁路，经过2263个省份，覆盖法国大陆323个地区首府并接通55处大陆港口。主要干线3级、次干线2级、地方支线及科西嘉窄轨1级。73处新增枢纽包含巴黎、里昂、斯特拉斯堡、梅斯、图卢兹等重要城市；现有港口本身能够承担海运补给，同一省份不重复堆放枢纽。复用已按2.2.0重制地形校正的已有补给站模型，坐标核对所属省份，不重复添加模型。

原模组铁路、补给站文件为空，而且所有法国政权开局获得隐藏精神“补给消耗－100%”。本版停止发放该精神，保留旧ID并将其修正值置零，旧存档也恢复原生补给需求。步兵、炮兵、摩托化等兵种仍使用游戏自身补给消耗，没有额外倍率惩罚。普通十营步兵师的营级基础需求合计0.6，后勤连、地形、天气与已有民族精神继续参与游戏计算。

法国政权一次性获得4列基础火车、20辆卡车，每个拥有的法国州另给2列火车、4辆卡车。单州通常得到6列火车和24辆卡车。区级、21大区开局均按所属法国州计算；AI与玩家同样配发，合并或占领不会再次领取。开放基础蒸汽火车和摩托化科技以便自行补充运输装备。储备是开局缓冲，不覆盖长期扩军；未自动消耗工厂、不额外发放部队。

铁路只有位于自己或可通行地区的连续线路才能供给本国枢纽，不能把敌方线路当成免费通道。铁路断线、火车不足和山区末端需要管理。小政权的首都和胜利点提供原生地方补给，统一后的大部队更依赖干线、枢纽与卡车。科西嘉使用海港与岛内铁路，南部萨尔泰讷、博尼法乔采用公路/海运，没有跨海铁路。

新开局直接生效；旧存档重启游戏后，在“铁路与补给”决议执行免费的“更新铁路与补给网络”。该决议不要求和平，只补缺失的铁路连接与枢纽，已有铁路等级保留；全存档一次性标记、防止重复领取。新开局不显示迁移决议。没有新增周期扫描、每日事件或宣战行为。

大陆以SNCF Réseau现行及停用普通线路的公开几何数据引导寻路，再按传统城市走廊和游戏省份连接构建。已排除现代高速、机场支线等编号家族，但现行数据不能证明所有支线在1936年存在：地区首府接入是玩法近似，等级是游戏平衡，并非精确的1936年铁路清册。线路优先接近普通铁路参考并避开高海拔，所有实际省份必须在位图中直接接壤；省份质心连线仅用于预览。

科西嘉历史采用CFD的铁路史：巴斯蒂亚—阿雅克肖中央线、蓬特莱恰—卡尔维支线，以及1935年9月通车至韦基奥港的东海岸线。后者1943年被毁，现行CFC地图已经没有它。本版按1936年补回该线；战前未建成的阿雅克肖—普罗普里亚诺和博尼法乔延伸线不添加。岛内路径同样为省份尺度近似。
