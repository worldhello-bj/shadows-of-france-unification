# 布列塔尼国策精简改造

参考本机日本国策树的主题分区、互斥优先方向和实质阶段奖励，按法国大区的体量重组。原175个地方节点缩为56个，另外保留6个全国重生节点。防御／进攻的72节点长链收拢为两条各4项的陆海军优先路线。地方政治已有三条内阁选择，因此不再重复加载通用党派短国策分支。

政治、经济、中立与动员、陆军、空军、海军从独立入口发展，主要跨分支条件只保留共同体章程、战争授权等实质制度节点。35天任务完成准备或制度转折，70天工程、研究院和终局组织给出明显收益。经济两方向、三个执政联盟、陆海军优先和驱逐舰／潜艇路线均有互斥取舍。

议事局一次开放六位议员协商，并提供巴翁、普里让的首轮支持。常设委员会提供特雷曼坦协作。新的支持协议持续540天，地方支持、故乡控制权、席位替换和委员会机制保留。关键立法由国策直接通过，不再强制先完成国策、再等待同一法案投票。

实体建设提供3座民用工厂、2座军用工厂和4座船坞，分别落在雷恩、莫尔莱、坎佩尔、布雷斯特和洛里昂。工程与奖励都重新核验拥有及完全控制，并使用一次性领取标记。研究依4／12／20座工厂逐步扩至3／4／5槽，奖励再次检查槽位上限；已有4槽仍可完成科学协会取得其精神。

南特转运与诺曼底护航为实际双边事件，对方接受／拒绝决定收益，领取由待回应标记控制。阵营资格沿用共同防御总纲，孤立精神仅限制宣战，不再覆盖阵营资格。战争授权仍由议会支持和战争支持度约束。

国家、原国策与事件ID保留。退役国策ID在兼容文件定义，不加载进可见树；军工组织、人物、决议和界面引用已指向合并后的节点。旧档迁移按旧领取标记恢复保留节点的完成状态，保存已赚取的实体收益，不补发合并后的奖励。旧档迁移与效果尚需实机测试，建议新开局体验完整奖励。

沿用模组已经提供的布列塔尼主题插画，并补充可见节点高亮。设计文件与源码布局预览不能替代游戏画面。

2026-10-11验证记录：56个地方节点与6个全国节点的加载、引用、互斥、连线、图标高亮及中文本地化通过源码检查；48组路线可达，科研边界、工程领土、双边回应和旧标记迁移通过针对性效果模型。利穆赞63项专属树的既有检查同时通过，其他国家的全国重生节点内容保持原样。

23个文件已安装到本地创意工坊模组并核对哈希，原文件备份保留在本次工作输出目录。初始引擎加载无本次改动的脚本或资源错误，也未生成新的崩溃目录；现有布列塔尼条件式人物招募仍产生引擎建议提示。检查完成后已关闭本次测试进程。验收范围限于源码、安装、引擎初始加载和针对性效果模型，尚未打开战役、检查游戏内布局或实测旧档迁移。
