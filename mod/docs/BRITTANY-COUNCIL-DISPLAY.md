# 布列塔尼议会显示修复

议会标题、关闭按钮和四个页签固定在窗口上方，正文使用独立的横向与纵向滚动区域。正文画布为980×650，六位议员的卡片采用两列三行，法案、军事和委员基金沿用各自页面。成员卡片内的文字与按钮使用相对坐标；关闭和分页始终位于正文之外。

扩大议会状态、支持期限、议员姓名、法案状态与底部提示的文字区域。打开议会立即更新席位图标状态，保留当前页签。100席、六位正任及候补代表、协商费用、支持期限与既有表决条件保持原状。

议会的九个国策采用简洁的树上名称，完整全国叙事与国策条件留在描述中；同步现有中英文本地化定义及议会提示。国策、事件和人物ID保持原状，奖励及分支图不变。

按源码布局生成的界面预览和树图用于审阅。源码几何检查、安装校验与初始引擎加载结果保存在本机工作输出目录；原生战役界面的实际绘制仍需游戏内验证。
