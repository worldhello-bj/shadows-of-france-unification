# 利穆赞／利摩日专属国策

基于6.0.6及2026年10月9日的启动修复，LMG新增57项地方国策与6项全国重生国策，共63项专属节点，并接入现有执政党短分支。二十个大区专属树之外，原本唯一沿用通用树的大区现在也有自己的路线。

地方政治采用市镇社会主义与激进派地方共和两条互斥路线，接入实际执政党身份与本地内阁。经济涵盖利摩日窑炉、电工瓷件、罗格朗工场、奥比松织造、贝拉克乡村信贷和蒂勒兵工。军事包括预备役、乡村运输、于塞勒与科雷兹阵地、通信、航空保障和统一战争授权。

工程分别落在326利摩日、309贝拉克、312奥比松、354蒂勒、363布里夫和349于塞勒，要求法律拥有且完全控制。一次性领取标记与州工程标记防止重复建造；失去利摩日或蒂勒时，对应工场精神停用，收复后恢复。五个工厂工程各增加一个共享槽位和一座工厂，州人口和初始工厂配置保持原有值。

技术讲习班、技术学校、应用研究院分别需要4／10／20座工厂，可增至3／4／5个科研槽。已有对应槽位时自动跳过，奖励再次检查上限。

全国使命、中央／联邦宪章、统一判定和两阶段谈判沿用当前全国重生机制。LMG加入大区资格名单。中央高原技术协约由克莱蒙费朗实际选择接受或拒绝，拒绝返还25政治点数。

1936年大区剧本移除LMG的通用国策预完成记录，以新树开始。旧通用树存档在启动或每周更新时保留已完成的共享党派国策、现有部队、工厂、科研槽与精神，并转移五项入门检查点；不补发这些检查点的奖励。通用分阶精神仍遵守最高阶段替换。建议新开局体验完整新内容。

图标使用已经随模组提供的主题插画。本次没有新增独占美术；全部地方节点有中文名称与独立描述。渲染预览是源码布局图，不能代替游戏画面。

## 本地验收（2026年10月11日）

源码结构、引用、本地化、图标及布局检查通过，53组效果模型覆盖科研门槛、工程防重领、控制权变化和旧通用树迁移。21个大区均选中各自专属树；其他国家的通用树保留。

已安装到本机现有模组目录，原文件留有备份。HOI4调试启动完成初始脚本与资源加载，测试进程正常响应，没有本次新增的脚本、资源或图标加载错误。五位本地内阁角色沿用既有党派系统的条件式运行时招募，以支持旧存档；引擎对其招募位置各提示两次建议性警告，单独记录。
