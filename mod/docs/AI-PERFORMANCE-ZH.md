# 2.4.0：统一战争AI节奏与性能调整

AI继续追求统一，但每次只为一个选定目标提供额外进攻权重。玩家的宣战、国策、战争目标和决议可用条件保留。

## 进攻准备

- 仅适用于使用统一国策树的AI政权，仍需取得统一战争授权。
- 自身处于和平、有至少3个师、可用人力超过1000、稳定度超过35%，才可选择目标。
- 目标必须满足原有法国统一目标条件：排除自己、属国、宗主国、同阵营、互不侵犯条约及已经交战对象。
- 目标当前不能处于战争，也不能属于阵营。自身估计兵力必须超过目标的1.15倍。
- 优先选择已经有战争目标的接壤政权；没有合格的陆上目标时，才检查科西嘉。海上目标仍需对应国策和至少4艘军舰。
- AI边境战争目标决议权重从12降至2，且每次只取得一个合格邻国的战争目标。玩家仍可一次取得原有全部合法邻国战争目标。地区国策原有战争目标奖励保留。

## 战争节奏

首次启用节奏控制时休整90天。当前战争结束后休整90天，再重新考虑目标。若战争通过特殊脚本结束而未经过和平会议，每月补检也会识别和平并重新开始90天休整。

目标选择由每月调度的隐藏事件执行，延迟7至45天，避免所有国家在同一天选择目标。同一国家最多排队一个选择事件；事件触发时再次检查和平、休整及部队状态。

每次只保存一个国家专属目标，不使用全局事件目标。计划120天到期；开战、目标被吞并、目标加入阵营、兵力变化、失去战争目标等情况会取消额外进攻权重。无合格目标或目标失效时短暂等待30天，避免连续重选。

通过原生 `avoid_starting_wars` 给统一AI施加-1000的整体征服偏好，选定目标的1100征服权重抵消后净值为100。宣战权重由250降为125。这里只调节AI倾向，没有硬性禁止外交行动；阵营参战、敌人主动宣战及其他脚本仍可能带来多线战争。

## 性能调整与验证范围

原656组陆上/海上策略合并为328组目标策略及1组克制策略，数量减少约49.8%。目标策略首先检查单个国家标记，未选中的目标不必进入后面的地域、外交和实力检查。未完成国策或正在战争/休整时不扫描新目标；陆上选择只检查邻国，全局搜索仅在可执行科西嘉行动且无合格陆上目标时执行。

矿区民族精神的补检由每日改为每周，按固定时间长度计算例行补检次数减少约85.7%。占领或失地、吞并、投降、和平会议、矿业国策完成依然即时刷新。特殊脚本绕过这些钩子时，最多等待下一次周补检修正。

原有旗帜、地图、人口与地区等级、首府胜利点、资源、工业、国策奖励和玩家外交条件保留。没有降低全局AI频率，也没有添加新部队或增加工业。

核验使用当前安装的1.19.3原生脚本文档、国策与事件解析、单目标/冷却/外交/实力场景模拟、完整独立包校验和安装后哈希比对。策略数量与补检次数的减少是结构指标；尚未启动游戏测量帧率、内存占用、推进速度或实战AI表现。建议新开档观察。

新节奏标记会在每月补检中初始化，便于已有存档进入新规则；已发生的战争、已有战争目标和存档中保留的旧策略不会被强行删除。旧存档中的旧策略是否即时被引擎清理尚未实测，新开档最可靠。
