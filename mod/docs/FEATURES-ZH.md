# 法兰西之影：史实矿区与专属国策

## 核对结论

原版527个地区中，开局资源只出现在10个不可通行的边界地区，每处4000单位；法国可玩地区没有资源。这些边界资源库配合原模组的贸易设计使用，属于玩法抽象，本次保留。原版另有4个国策在随机自有地区凭空增加50单位铁、铝、钨或油，橡胶国策也随机增加50单位橡胶；现已改为有矿址约束的扩产与合成工业。

矿种、已知开发时期和所在区域有史料依据；游戏数值是保守的平衡单位，不是储量、吨位或对1936年产量的精确复原。铁矿用游戏钢资源体现，铝土矿用游戏铝资源体现。煤采用本机1.19已有的煤炭资源；钾盐没有对应资源，使用配套民用加工工业体现。

### 地图定位与时期限制

矿址市镇使用法国政府市镇数据，分别投影市政府和市镇中心坐标，并读取模组省份位图与地区列表。20个市镇的40个定位点均落入预定矿区地区；坐标校准误差约6像素，不能据此宣称精确复原每个矿井或矿层边界。

阿扬日位于地图编号98，原模组显示名为“蒂永维尔东区”，实际像素位于蒂永维尔以西；佩谢尔布龙对应127“维桑堡”，而不是斯特拉斯堡；维泰尔赛姆钾盐矿对应214“坦恩”，维滕海姆对应217“米卢斯”。本轮以实际像素位置选择奖励地区，未更改地区ID或边界。

萨洛钨矿没有加入1936年的开局资源或国策：现代开发始于1971年，不能把现代矿业清单直接搬进1936年。[法国国民议会说明](https://questions.assemblee-nationale.fr/q16/16-2785QE.htm)。

洛林米内特含磷铁矿和托马斯脱磷工艺的背景另见[洛林大学资料](https://rpn.univ-lorraine.fr/UOH/RPL/co/c_18_b_17.html)。瓦尔铝土矿的战前记录另见[1931年地质文献](https://www.persee.fr/doc/geo_0003-4010_1931_num_40_226_11192)。

## 专属国策

先完成原有“基础设施建设”，再进行“实地矿业调查”。每个新国策耗时35天；调查给予一次100%工业研究加成，各地区分支各有2至3个连续工程。只有当前拥有并控制对应矿区的国家可进行工程，其他地区不能获得当地矿产。

工程标记保存在地区上，阶段奖励在该地区最多兑现一次，易主后仍保留。新主人接管已有工程的矿区后，可以跳过已完成阶段而不重复领奖，继续后续阶段；持有尚未建设的合格矿区时仍需要施工。后续阶段必须在同一地区已有上一阶段工程；失去矿区控制会使国策失效并取消。工厂工程先增加对应槽位再建厂，适用于原地图开局5/5满槽的城镇；工厂与炼油厂仍遵循引擎建筑上限。每项国策只选一处符合条件的矿区，不会把所有矿区同时加产。

地区资源本来就是对大片矿业和工业供给的抽象，因此矿区国策和通用资源国策的可用地区范围完全一致。

## 国策正文

### 实地矿业调查

调查队将矿井档案与地方报告放在同一张地图上。矿产不能只靠政府的愿望产生，开发工作必须从已有矿区与可靠记录开始。

需要拥有并控制至少一处核实的矿区。完成后获得一次100%的工业技术研究加成。

### 洛林米内特铁矿

矿灯照亮低品位含磷铁矿的掌子面。我们将改善抽水、提升与矿石分选，让洛林的矿产更稳定地进入冶炼环节。

需要拥有并控制相应矿区，并满足前置项目条件。完成后在一处符合条件的矿区所在地区增加12单位钢资源。同一地区的同阶段工程只能建设一次。接管已建矿区时，可跳过已完成阶段而不重复领奖，继续后续工程。资源数量是游戏平衡单位，不代表真实吨位。

## 获得、失守与升级

- 实际控制矿区即可获得基础精神，战时占领有效，无需先吞并或成为核心。开局控制国同样获得，AI与玩家使用同一规则。
- 失去全部有效矿区后撤销，夺回后恢复。多个国家分占同一矿带时，可各有基础精神；每国每组只保留一个等级。
- 整合精神需要控制该组全部地区，且其中至少一处完成矿业分支的末阶段工程；这是与上一版“国策只施工一处矿区”相配合的设计。
- 失去部分地区则降级；失去全部则撤销。工程标记留在地区上，接管已开发矿区可以继承整合效果，无需重做工程。
- 埃沙西耶尔须先完成马泽钨矿复采或通用钨矿扩产，才有基础精神；未经复采的矿脉不提供产出加成。

# 法兰西之影 1.4.0：统一战争

1.4.0 在优化汉化版中加入24个国策，将原有21个地区征服国策纳入统一路线。全树共153个国策；108个原有非征服国策、矿区、加强后的矿业民族精神和现有图标保持一致。

## 路线与节奏

共同纲领 → 动员名册 → 参谋联席 → 统一战争准备，是各法国政权均可采用的主干。四个准备国策各21天，不要求先完整拥有一个大区。

完成准备后可选择地区战役。21个地区战役各7天，互相不设固定顺序，地图图标保留；只对合法目标发战争目标，完全拥有并控制本地区时自动跳过。已有目标不重复创建。

军械库、教官交流、铁路统筹、宣传广播、工业协调、军医与老兵构成军需支线。地区政务在控制6州后开放，12州可整合已拥有并控制的法国领土为核心，20州建立统一总指挥部。巴黎委任要求拥有并控制巴黎；全国会议要求控制至少100州。

最终“法兰西重归一体”要求独立、和平、拥有并完全控制339个法国地区；完成后使用母模组的 FRANCE 国名、巴黎首都143、全部法国核心与组建国家标记。地区战役跳过与核心整合也检查完全控制；州内仍有敌方省份时不会提前完成。

战后可推进军需转产、全国重建、共同规则和全国市场；新的永久精神支持工业和稳定度。

原有“统一法国”决议同步要求完成全国重建会议、独立、和平并完全拥有及控制339州，调用与最终国策相同的建国效果。通过决议建国后，最终国策自动跳过，奖励只领取一次。

## 统一战争奖励

| 精神 | 效果 |
|---|---|
| 统一战争动员 | 征兵人口+1%、战争支持度+10%、动员速度+25%、计划速度+15% |
| 统一战线总指挥部 | 替代初级动员：征兵人口+2%、战争支持度+15%、计划速度+25%、陆军攻击+10%、补给消耗-10% |
| 统一战争铁路统筹 | 补给消耗-10%、基础设施建造速度+15% |

| 法兰西统一市场 | 民用工厂建造速度+20%、消费品工厂系数-10% |

完成统一后撤销全部三个战时精神，初级动员和总指挥部不会叠加。民主政权在动员期间允许向同意识形态目标宣战，战时精神移除时恢复民主政体规则。该规则本身属于国家级；本扩展授予的目标和AI偏好仍限定法国政权。

## 更积极的统一战争AI

准备主干的 AI 国策权重为12，地区战役为8，后续主要路线为6。为本地图328个可能以法国州为首都的国家分别配置动态有效的策略；每个国家两组：大陆与科西嘉海上战役。

区级开局的多数政权只有师模板。统一纲领启动后，少于2个师的AI优先完成原有“区级政权”和“三个步兵师”国策（选择系数40），同时优先基础设施、基础工业、炮兵与支援科技；拥有至少2个师后结束建军计划，再按有效目标准备进攻。建军奖励沿用原有国策。

有合法战争目标时，AI对邻国的征服权重+300、备战+200、宣战+250、对抗+100。策略要求行动方和目标均为以法国州为首都的独立、未投降国家；跳过自己、同阵营、主附庸、互不侵犯条约和已交战对象。进攻方至少2个师、没有正在进行的战争、相对军力高于目标的75%。条件改变即撤销该策略。实际宣战仍取决于游戏AI、外交限制、兵力和路径。

科西嘉使用独立的海上计划，要求已完成海上通道国策、至少4艘舰船、符合目标条件，并额外提高入侵倾向。实际登陆仍需要运输与可用舰队。

“制定下一轮边境战役”花费25政治点数、冷却90天，和平时向尚无目标的法国邻国补发730天吞并目标；AI会主动使用。国策同样使用730天目标。本扩展没有直接强制宣战，也没有修改影响所有国家的全局AI参数。
