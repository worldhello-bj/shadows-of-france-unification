# 巴黎 · 二十国首版 3.0.0

巴黎保留原有66项国策和议会、督政互斥路线，增加14项公共预算与合作国策，共80项。新增两条短链均从共同的国家章程进入，不另锁定政治路线。原有领袖、意识形态、大区州集合与统一门槛沿用。

九个旧部署中的巴黎机动、工业和登陆分别并入平原、城市和两栖经验，永久且同类只取得一次。新增训练经验汇编与已获得的城市经验共用同一标记；不会再增加第二层。其他战时征募和战争总参谋部依原条件结束。

邻国归并邀约保留60政治点、对方可拒绝、和平独立无阵营、领土完全控制等条件。正式地方核心按2.13付费登记规则处理，行政国策不免费发放核心。

国策关系图来自实际脚本；静态前置、图标、数值与重复执行核对已列入二十国报告。实机界面、旧档和战役平衡仍待验收。
