# 人口与地区等级重制 · 2.3.0

两种剧本均从1936年开局，本版采用法国INSEE历史人口表的 PTOT1936 列。将34,765条法国本土及科西嘉市镇记录逐条分配到现有地图，合计41,813,397人。旧模组同一法国范围为335,023,058人。

## 等级与工厂槽位

以下人口阈值是本模组的玩法规则，并非法国官方行政等级或钢铁雄心4自动人口公式。所有等级名称与槽位使用本机游戏原生定义；小城镇沿用模组既有3槽定义。

| 1936年州人口 | 地区等级 | 基础共享工厂槽位 |
|---|---|---:|
| 0 ≤ 人口 < 25,000 | 牧区（pastoral） | 1 |
| 25,000 ≤ 人口 < 50,000 | 农村地区（rural） | 2 |
| 50,000 ≤ 人口 < 100,000 | 小城镇（small_town） | 3 |
| 100,000 ≤ 人口 < 200,000 | 城镇（town） | 4 |
| 200,000 ≤ 人口 < 350,000 | 大城镇（large_town） | 5 |
| 350,000 ≤ 人口 < 600,000 | 城市（city） | 6 |
| 600,000 ≤ 人口 < 1,000,000 | 大城市（large_city） | 8 |
| 1,000,000 ≤ 人口 < 2,000,000 | 大都市（metropolis） | 10 |
| 2,000,000 ≤ 人口 | 特大都市（megalopolis） | 12 |

地区等级决定基础槽位。原有工厂、基础设施、资源、军队和国策奖励保留。若初始共享建筑数量超过新的基础槽位，则在州历史中按原生 add_extra_state_shared_building_slots 效果补齐已有工业的占用，不抬高人口等级。新增工厂需遵守剩余槽位；这不是根据人口新建工厂。

## 空间对应与特殊情况

人口年份为1936年，市镇统计范围为INSEE回溯到2025年边界的口径。先使用官方市镇所属行政区，再按模组实际省份像素细分已合并行政区、海岛和卢丹等单独片区。边界附近人口是对游戏地图的分配估计，不宣称重建了1936年的全部行政边界。市镇合并、地图简化及约6.2像素的地理定位误差限制了细小边界的精度。

巴黎按20个市辖区合并，人口2,829,753；楠泰尔、博比尼、马恩河畔诺让等郊区分别统计，不将巴黎市与整个都市圈混用。里昂、马赛使用全市市镇记录，不重复添加市辖区。所有市镇人口恰好使用一次，不再通过总人口系数放大。

勒旺岛（483）和波克罗勒岛（484）属于耶尔市镇；本表没有单独的1936年岛屿人口统计。因此市镇人口只计入大陆州，两岛不另增加可征募人口，等级采用小型岛屿（1基础槽）。其单独统计人口在核对表中留空；游戏中的0表示未分配独立市镇人口，不表示两岛历史上无人居住。

法国统计范围为342个州。184个不可通行邻国边缘州和海灵岛（48，地理上属于英国）共185州保留原人口、等级及历史。上游海灵岛的法国归属问题未在此人口重制中改动。

采用人口表自身合计41,813,397，不强制缩放为当年发布的其他全国总数：统计边界与INSEE回溯口径并不完全相同。法国的可征募人口将随真实人口明显下降；既有征兵法律、民族精神和部队不额外加强。

## 核对与安装

POPULATION-STATE-LEVELS.csv 列出全部342州的人口、等级、基础槽、已有工厂及补充槽。POPULATION-LEVELS-ZH.png 为数据示意图，并非游戏截图。人口与地区等级在新开档时载入；旧存档不会自动迁移人口。
