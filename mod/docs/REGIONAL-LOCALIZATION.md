# 大区国策本土化

逐区核对21棵地方树及其党派、公共附加树。地方建设以原有省界为准，吞并不扩大本省投资范围。党派计划根据执政大区显示名称与产业主题。

边界按1936.1.2.1省份阶段的实际归属核对，补入旧名单遗漏的普瓦图州525、527和中央州526；不更改领土历史或统一系统。

科西嘉改用山地道路、岛内工场、燃料仓储与沿海港区等主题；萨尔泰讷项目实际投放第509州。原先随机新增钢铁资源的三项奖励改成材料采购预算，每次40政治点；保留其他原有建设数量、容量限制、研究与政治奖励。矿产扩张仅使用已有的真实矿区分支，外省矿区不显示为本省计划。

船坞和港口建设要求本省自有且完整控制的沿海州。统一后的全国职责、外交合作和边境统一战役保留原有范围。国家、国策和事件ID、前置关系、天数、布局、旧存档一次性标记均保留。

验收范围为源码、源文件树图、安装一致性与引擎初始加载。尚未进行游戏内界面、独立战役或旧存档奖励验收。

已完成源码、树图、安装一致性及引擎初始加载核对；游戏内界面、战役和旧档仍未实测。
