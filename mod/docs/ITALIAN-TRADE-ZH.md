# 意大利钢铁与海运贸易 · 2.9.7

意大利原有4000单位铝出口池保留，在原资源枢纽477州新增4000单位钢。沿用边境贸易国的full_export（100%出口）规则与原有非参战定位。这些是同原模组德国、奥地利4000单位钢一样的外部供给抽象，不代表意大利矿山的真实储量，也没有给意大利增加工厂或作战部队。

原意大利48州全部没有港口。仅开放其现有首都与资源枢纽477州的可通行属性，并在属于该州的实际海岸省17903配置4级海军基地；该省与海洋省18930实际接壤，有既有港口模型位置，并能通过海洋连接科西嘉五个地区港口。资源、首都与出口港处在同一个可通行州，避免跨越其他不可通行边境州。其他意大利州的不可通行状态保留。意大利新开局配置20艘商船。

新开局直接在原生贸易界面购买意大利钢或铝。正常工厂付款、买方运输船、资源供给与航线限制继续生效；没有通过民族精神凭空免单，也不把法国真实矿区奖励改成外部资源。

旧存档重启游戏并载入后，在决议“意大利贸易”中执行“更新意大利贸易设施”。仅意大利仍拥有并控制477州、尚未更新时出现；玩家免费执行一次，为意大利增加4000钢、把指定港口补到至少4级并增加20艘商船。已有高于4级的港口不降级，现有钢资源和商船不会清零。已初始化的新存档不会重复领取。资源初始化标记属于意大利，全地图只有一次，多个玩家也不会重复刷取。没有新增周期性扫描。
