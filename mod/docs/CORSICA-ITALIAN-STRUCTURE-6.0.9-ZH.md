# 科西嘉国策结构修复 · 6.0.9

科西嘉国策树恢复意大利式的分区与相对布局：工业、陆军、空军和海军分别成列；共和国、统帅、委员会政治路线纵向分流；大陆外交和全国统一位于后续区域。保留国策 ID、前置、互斥、可用条件和本地区建设。修正合并航母项目与后续海军国策处于同层的问题，调整全国战略延续的上下关系，并补充路线快捷入口。

继承的意大利动态修正也统一为整数步长，补上68项具体长期奖励提示；旧变量在启动和首次每日同步时整理，保留国策完成及领取标记。民族精神与制度成长继续采用每项主能力+2%、基础10%／20%／30%、地区优势12%／24%／36%、副项5%／10%／15%的方案。旧存档实际读档和游戏内界面尚未验收。

布局依据本机 1.19 版意大利国策源码，转换其分支坐标与相对锚点；不重新导入意大利领土、建设或人物效果。

工业、陆军、航空、海军位于前半部；共和国、统帅和委员会分支保留原有选择规则，委员会继续分出军官、文官与君主路线。全国宪制放在后续区域，远征战略从宪制入口下方展开。

改动范围为科西嘉本地树、该国的共享全国段坐标、科西嘉继承修正的整数处理与提示。其他大区的国策位置及前置关系不变。主要修正增量采用偶数步长，使组合后的单项动态精神修正仍为整数倍；登陆容量按师数量处理。

验证范围：源码渲染、关系与整数奖励检查、安装核对、引擎初始加载。实机点击、完成前后收益及旧存档读档尚未验收。
