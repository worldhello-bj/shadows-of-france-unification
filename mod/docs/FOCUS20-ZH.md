# 法兰西之影：二十国策版 3.0.0

18个新专属国策树，巴黎80项、科西嘉72项扩展；总计20国1,408项可见国策（含互斥路线）。利穆赞沿用通用树，其他法国区级国家沿用通用树。

六类战役部署改为永久的小型地形经验，同类只取得一次，统一后保留；巴黎同类并入公共规则。国策入口、短中文标题与原生决议用于展示地方财政、生产、运输和协约。

每国三条政策路线互斥，经济工程受本地拥有与控制条件限制。原有大区剧本预完成国策改为显式一次性开局效果，避免指向已更换的通用树。占领治理沿用2.13.0的付费整合与顺从抵抗条件。

本包在工作目录隔离构建，旧版回滚备份位于focus20-pass。推荐新开档。静态和模拟结果见verification.json；实机与旧档兼容范围按该报告列明，不能把打包成功视为实机验收。

安装：解压后运行install.ps1，启用独立中文版。不要在正在运行的游戏中更新安装目录，重启后再载入新版本。
