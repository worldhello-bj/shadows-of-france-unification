## 主线与政治选择

重召开岛民议会 → 皮耶韦协约 → 全岛统一授权 → 五地归于同一议会。

政治路线二选一：

| 路线 | 前置链 | 核心精神 |
|---|---|---|
| 波拿巴传统 | 阿雅克肖的遗产 → 波拿巴派议政会 → 远征参谋传统 | 陆军攻击+12%、计划速度+15% |
| 帕奥利共和传统 | 科尔特的共和国 → 岛民议会宪章 → 公民军官 | 稳定度+15%、生产效率增长+15% |

两条路线在全岛统一后汇入“从岛屿走向法兰西”。选择代表政治传统，不复活历史人物，也不自动更换现有领导人、意识形态和国家人物体系。

## 四条建设路线

| 路线 | 建设重点 | 具体支持 |
|---|---|---|
| 岛屿经济 | 村道、合作社、技术学堂、兵工作坊、水力设施 | 2民工、2军工、2研究槽、基础设施与技术奖励 |
| 海军与运输 | 港务、海运署、船厂、护航队、运输训练、海空侦察 | 2船坞、4早期驱逐舰、基础运输技术、共100运输船单位、岛内航空基地 |
| 登陆部队 | 山地守备、征募、轻武器、登陆团、炮兵、军需 | 4000可用人力、2700基础步兵装备、2支四营海军陆战团、作战经验与登陆/补给加成 |
| 全国整合 | 桥头堡、共同政务、罗讷走廊、矿区工业协作 | 对完全掌握的法国地区建立核心，争取大陆工业、巴黎与全国授权 |

工业设施只建设在我方拥有并控制的相应区域，共享建筑同时提供所需额外槽位。科西嘉的水力建设不增加虚构煤铁矿藏。研究、工业与可用人力属于架空玩法奖励，州人口和地区等级沿用1936年数据。

四艘军舰分别适配启用与未启用“炮手就位”的装备体系，使用本国早期驱逐舰型号，并解锁所用基础舰艇模块的技术。舰队与登陆团设置一次性交付标记，重复调用奖励不会重复创建单位。它们提供行动基础，仍须训练、部署、制海权和玩家或原生AI实际下达登陆计划。

## 两条大陆航路

“向大陆发出统一宣言”需要全岛完整拥有并控制、和平以及至少4艘军舰，同时完成政治使命、运输训练和远征军建设。

- 普罗旺斯航路：优先土伦，其次马赛、蒙彼利埃。
- 蔚蓝海岸航路：优先尼斯，其次土伦、马赛。

两条航路互斥。每次只对一个合法的当前港口拥有者取得吞并战争目标，排除自己、盟友、附庸、宗主国、互不侵犯及已有交战关系。战争目标有效期730天。完成航路不自动宣战、转移州或创建桥头堡。

若港口归属变化或战争目标到期，可以在和平且尚未建立桥头堡时使用“重新规划大陆航路”：35政治点数、120天间隔，按已选择航路重新检查当前合法目标。

桥头堡要求尼斯、蒙彼利埃、马赛或土伦至少一州完整拥有并控制。“大陆共同政务”继续使用既有核心整合规则，仅核心化完全拥有、完全控制的法国地区。需要的资源区必须实际掌握，资源量和矿区控制精神继续沿用此前核对的数据。

## 巴黎与最终统一

- 巴黎委任：完整拥有并控制巴黎，控制州数超过20。
- 全国重建会议：完整拥有并控制巴黎，控制州数超过100，处于和平。
- 最终建国：完全拥有并控制既有统一判定中的339个法国州、独立、和平，且完成全国会议。

最终国策与原有建国决议共用一次性宣告效果：迁都巴黎、采用法兰西国号、撤销统一战争临时精神并给予既有重建奖励。建国决议认可通用树或科西嘉树的全国会议。科西嘉登陆训练与远征军临时精神也在建国后撤销，后续重建国策提供工业+15%、研究+10%的共同未来精神。

## AI与两种开局

科西嘉使用专属优先计划，同时接入2.4.0的单目标、超过1.15倍实力、至少3师、可用人力超过1000、稳定度超过35%、和平与90天战后休整条件。跨海目标仍需至少4舰。仅在完成大陆航路后，科西嘉AI才可考虑法国南岸的非接壤目标；未加入阵营、未参战等原有安全检查仍有效。

这是AI偏好与准备能力的配置，不能保证原生AI在所有地形、舰队和外交情况下成功组织登陆。没有强制宣战或自动吞并。其他政权的原153个国策逐字节保留；专属树建议新开档体验，现有存档的国策树不会被强行切换。

阿雅克肖的大区开局历史中原有28项通用国策完成标记已经不属于新树，故仅移除这些标记；其岛屿、人口、建筑、部队文件与政治数据保留。旧国策的完成奖励不再通过这些标记发放，新树从共同议会开始，避免预先完成旧树奖励造成重复或无效引用。
