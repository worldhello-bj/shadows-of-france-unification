# 巴黎国策本土化

巴黎地方建设以既定法兰西岛25州为本土范围，城市或省份阶段均只在实际拥有并完整控制的本土州兑现，修正将布列塔尼、诺曼底、香槟、卢瓦尔写入本省投资计划的问题。塞纳工业带、近郊工场、市政预算、大学与工程学校等主题替代全国投资叙事；中英文显示同步，主要建设节点使用已有巴黎专属图标。

地方建设、用地和相关合作改善限定在本省完整拥有并控制的州，即使后来扩张，也不会随机在其他大区建设。舰队分支必须实际拥有并完整控制法国沿海州；船坞附带用地也限定于实际海岸。对其他大区的外交与统一目标保留其地区身份。

保留149项国策的ID、连线、互斥关系、耗时、原有收益数量、容量上限、科研门槛及领奖标记，不补发已完成国策收益。没有修改国家边界或开局领土。验收沿用源码、安装和初始引擎加载范围；战役、旧档和游戏内界面另待实测。

本轮验收：源码与建设选择模型检查通过（729个场景）；13个文件已安装并逐项核验，初始引擎脚本和资源加载没有新增诊断。整模组仍有基线已有诊断。本土范围与省份阶段1936.1.2.1的历史归属一致，城市阶段不授予尚未取得的近郊州收益。中英文同键文案保持一致，内阁条件说明同步。国策位置和依赖保持原样，渲染图及节点中心检查通过；预览脚本语法通过检查。游戏内布局、战役和旧档未实测；此前浏览器策略阻止本地文件交互，本轮未重试或绕过。
