# 内阁与随机整合 · 2.9.1

直接打开政治面板，在“政府与内阁”和“产业与国防内阁”的八个原生部长槽位中点击任职头像或空位；使用游戏原生候选列表任命。八个职务各有三名候选，可同时任命八人。候选采用虚构法国官员模板，姓名不代表真实历史人物任职。不同国家共用模板；巴黎和科西嘉保留各自国策树。政治面板按本机KR 1.7的实际GUI布局移植，使用其领袖、国策、民族精神、分类网格位置及必要的界面边框。仅吸收政治面板与对应界面素材，并保留原生法律、通用顾问、科研生产和军事顾问；游戏无需安装KR。

## 开局随机整合

1936年1月8日前，法国地区玩家可在“开局版图设置”执行免费决议“随机整合法国地区：50个现存国家”。点击后先阅读游戏内说明，再决定是否执行；取消不占用次数。执行本局只允许一次，旧存档在截止日后不会出现。

50指全地图现存国家总数，包括保留的邻国。只有法国地区政权参与合并，外国国家、所有玩家、巴黎PRS和科西嘉COR不能被吞并。接收国可为法国玩家或AI，因此玩家也可能随机获得临近地区；不跨海强并孤岛。大区剧本本身少于50国时隐藏此决议。2.9.4起，开局已有战争也可执行。

每轮随机选择一个可以合并的法国AI政权，再随机选择其合法陆地邻国作为接收国。接收国维持原领袖、首都和国策树。吸收州成为接收国核心，保留人口、资源、建筑、地形、城市和胜利点；原部队不转移，避免把328份军队集中堆积。合并后增加90天AI战役休整。循环有512次上限，并在没有合法相邻组合时停止并显示实际剩余国家数。国家数比较按本机原生collection_size的包含边界规则配置，不会多合并到49国。

减少国家及开局部队旨在降低模拟负担，真实帧率/速度改进尚未游戏实测。地图示例使用实际省份接壤和两种剧本州归属运行同一规则；运行时由游戏随机种子决定，不预置固定版图。
